# Project Instructions

- Use Python 3.12 or newer.
- Use `uv` for dependency management and running commands.
- Run the application with:
  `uv run agent-test`
- Run tests with:
  `uv run pytest`
- Do not modify `.venv`.
- Do not read or modify secrets or credentials.
- Do not use `sudo` unless explicitly requested.
- Do not push Git changes unless explicitly requested.
- Prefer small, testable changes.
- Before modifying code, inspect the relevant files first.
